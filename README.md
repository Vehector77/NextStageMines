# NextStageMines
Sistema de minería por etapas con hook a BlockRegen y LuckPerms (regiones por rango).

Recuerda que para compilarlo requieres del plugin Blockregen.


Este plugin tiene varias funciones super utiles si tu objetivo es hacer un survival en el cual haya minas Puedes crear un sistema de progresion de minas el cual es totalmente customizable.

Ahora incluso compatible con rangos individuales.

Tambien incluye herramientas super utiles para staff las cuales podras ver proximamente en la documentación.

Sistema por regiones el cual puedes establecer que rango pueden entrar en tu mina y cuales no puede, esta funcion es por regiones asi que es totalmente customizable en ese aspecto.

Compatible con cualquier formato de color Hex minimessage legacy etc...

Cualquier funcion interesante que quieran que añada siempre me lo pueden decir para añadirla en un futuro!
